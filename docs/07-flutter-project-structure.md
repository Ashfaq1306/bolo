# 7. Flutter project structure

**Feature-first** organisation: each feature folder contains its own models, data, and UI. Beginners can find everything about "expenses" in one place, and two developers can work on different features without merge conflicts.

```
bolo/                                  ← git repo root (F:olo)
├─ app/                                ← Flutter app (package: bd.bolo.bolo_app)
│  ├─ lib/
│  │  ├─ main.dart                     ← boots Firebase (+ emulators in dev), timezone, notifications
│  │  ├─ app.dart                      ← MaterialApp, theme, l10n, AuthGate, HomeShell (bottom nav)
│  │  ├─ firebase_options.dart         ← generated by `flutterfire configure`
│  │  ├─ core/                         ← shared, feature-agnostic code
│  │  │  ├─ money.dart                 ← poisha ↔ taka, lakh grouping, Bangla digits
│  │  │  ├─ dhaka_time.dart            ← Asia/Dhaka helpers (today, combine date+time, formatting)
│  │  │  ├─ bangla_digits.dart         ← ০-৯ ↔ 0-9
│  │  │  ├─ labels.dart                ← enum → localized label/icon
│  │  │  ├─ providers.dart             ← the Riverpod dependency graph (override these in tests)
│  │  │  ├─ theme.dart                 ← colours, Hind Siliguri typography
│  │  │  └─ widgets/depth_card.dart    ← 3D-tilting card
│  │  ├─ l10n/                         ← app_bn.arb, app_en.arb (→ generated app_localizations.dart)
│  │  └─ features/
│  │     ├─ auth/                      ← anonymous sign-in, email linking
│  │     ├─ voice/                     ← SpeechService (speech_to_text), VoiceOrb (shader widget)
│  │     ├─ command/                   ← ParsedCommand, CommandService (callable), CaptureController,
│  │     │                               CommandSaver (the ONLY place proposals become records),
│  │     │                               ConfirmationSheet (the card)
│  │     ├─ records/                   ← models + RecordsRepository (Firestore implementation)
│  │     ├─ reminders/                 ← ReminderScheduler (local notifications)
│  │     ├─ summary/                   ← DailySummary (pure Dart, on-device)
│  │     ├─ inbox/                     ← offline captures (shared_preferences)
│  │     ├─ home/ tasks/ money/ settings/  ← screens
│  ├─ shaders/orb.frag                 ← GLSL fragment shader for the 3D orb
│  ├─ assets/fonts/                    ← Hind Siliguri (OFL)
│  └─ test/                            ← unit + widget tests (fakes/ has an in-memory repository)
├─ functions/                          ← Cloud Functions (TypeScript)
│  ├─ src/index.ts                     ← parseCommand (auth → quota → Claude → validation)

├─ docs/                               ← these documents
└─ .github/workflows/ci.yml            ← analyze + test both packages on every push
```

## Conventions

| Topic | Convention |
|---|---|
| Naming | Files `snake_case.dart`, classes `PascalCase`, providers end in `Provider` |
| Imports | `package:bolo_app/...` (no relative `../../`) |
| State | Riverpod `Provider` / `StreamProvider` / `NotifierProvider`, without code generation |
| Models | Immutable classes, a `copyWith`, and `toMap()`/`fromMap()` |
| Strings | **Never hard-code user-visible text** in widgets: use `AppLocalizations.of(context)` |
| Money | Always `int poisha`. Format only in the UI with `Money.format()` |
| Time | Never call `DateTime.now()` in features: use `clockProvider` so tests can fake time |
| Lints | `flutter_lints` plus a few stricter rules in `analysis_options.yaml` |
| Tests | Pure logic (money, dates, summary, command validation) must have unit tests |

## Key packages (and why)

| Package | Purpose |
|---|---|
| `firebase_core`, `firebase_auth`, `cloud_firestore`, `cloud_functions` | Firebase |
| `flutter_riverpod` | State management |
| `speech_to_text` | Platform speech recognition |
| `flutter_local_notifications`, `timezone` | Offline reminders, always scheduled in the `Asia/Dhaka` zone (no device-timezone lookup is needed) |
| `intl`, `flutter_localizations` | Bangla/English, number/date formatting |
| `shared_preferences` | Inbox & small settings |
